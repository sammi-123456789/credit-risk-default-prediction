# Credit Risk Default Prediction



An End-to-End Credit Risk Decisioning System built using Machine Learning to predict whether a loan applicant is likely to default.



## Project Overview



This project simulates a real-world credit risk pipeline used by banks and financial institutions. It includes data preprocessing, model training, business-oriented evaluation, and decision-making based on predicted risk.



## Features



- Data Cleaning & Preprocessing

- Feature Engineering

- Logistic Regression (Baseline Model)

- Random Forest (Advanced Model)

- ROC-AUC & Precision-Recall Evaluation

- Confusion Matrix Analysis

- Business Cost Evaluation

- Final Loan Decision Output
